Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aplicar conhecimentos de desenvolvimento web por meio da criação de um jogo da velha utilizando HTML, CSS e JavaScript.

A proposta foi construir uma página interativa, na qual dois jogadores podem participar de uma partida, alternando suas jogadas entre os personagens Lua e Sol.

Além do funcionamento do jogo, o projeto também apresenta conteúdos sobre a história dos jogos eletrônicos, programação e tecnologias utilizadas no desenvolvimento web.

Como o Jogo Foi Desenvolvido?

HTML

Responsável pela estrutura da página, organização do tabuleiro, menu e demais elementos.

CSS

Utilizado para personalizar as cores, o posicionamento, os tamanhos e a aparência dos elementos.

JavaScript

Responsável pela lógica do jogo, alternância dos jogadores, identificação de vitórias e empates.

A Importância do Bootstrap

O Bootstrap foi uma ferramenta importante durante o desenvolvimento deste projeto. Ele oferece classes prontas de CSS e componentes que facilitam a criação de interfaces organizadas e responsivas.

Utilizamos seus recursos para construir containers, menus de navegação, colunas, espaçamentos e outros elementos visuais. Isso ajudou a organizar o conteúdo e adaptar as páginas a diferentes tamanhos de tela.

Apoio de Inteligência Artificial

Durante a realização do projeto, ferramentas de Inteligência Artificial foram utilizadas como apoio ao aprendizado e ao desenvolvimento.

Essas ferramentas auxiliaram na compreensão de códigos, esclarecimento de dúvidas, identificação de possíveis erros e organização de ideias para melhorar a estrutura e a aparência do site.

A utilização dessas ferramentas teve caráter de apoio educacional, contribuindo para o aprendizado das tecnologias utilizadas.
